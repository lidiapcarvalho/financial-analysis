# Financial Analysis of Luxury Companies

## Project Overview

This project analyses the financial performance of selected companies in the luxury goods sector between 2020 and 2025.

The analysis will use Python to explore financial data, calculate basic financial indicators, and compare the evoluation of the selected companies over time.

The project is also a learning exercise to develop pratical skills in financial analysis, data analysis, Python, and financial data interpretation.

## Companies

The initial analysis will focus on three companies:

| **Company** | **Country** | **Reporting Currency** | **Business Profile**                                        |
| ----------- | ----------- | ---------------------- | ----------------------------------------------------------- |
| LVMH        | France      | EUR                    | Diversifed luxury group                                     |
| Kering      | France      | EUR                    | Luxury group with a strong focus on fashion and accessories |
| Richemont   | Switzerland | CHF                    | Luxury group with strong exposure to jewellery and watches  |

These companies were selected because they operate within the luxury sector while having different business profiles. This provides an opportunity to analyse both common patterns and differences in their financial performance.

## Analysis Period

The project will cover the period from **2020 to 2025**.

This period was selected to incluide the disruption caused by the COVID-19 pandemic, the subsequent recovery, and the following years of financial performance.

The analysis will focus on the evolution across the period rather than only comparing the beginning and ending years.

## Initial Financial Metrics

The project will initially focus on basic financial information and indicators.

### Financial Data

- Revenue
- Operating Income
- Net Income
- Total Assets
- Total Liabilities
- Shareholders' Equity

### Financial Indicators

- Revenue Growth
- Operating Margin
- Net Profit Margin
- Return on Assets (ROA)
- Return on Equity (ROE)

Additional metrics may be introduced as the project develops.

## Currency Coversion

LVMH and Kering report their financial information in euros (EUR), while Richemont reports in Swiss francs (CHF).

The original reported values will be preserved in the dataset. When necessary for comparison, Richemont's financial data will also be converted to euros using documented exchange-rate data.

This allows the project to explore currency conversion as part of the financial analysis rather than treating the difference in reporting currencies as an obstacle.

## Data Sources

Financial data will be collected from publicly avaible company reports and investor relations materials.

The specific source for each datasetor financial figure will be documented during the data collection process.
